YouHost — ASENNUSOHJE
=====================

1. Pura zip kaksoisklikkauksella.

2. Siirrä YouHost.app kansioon Ohjelmat (Applications).

3. Ensimmäisellä käynnistyksellä macOS voi estää ohjelman. Klikkaa YouHost.appia oikealla ja valitse Avaa. Tai avaa Järjestelmäasetukset > Tietosuoja ja suojaus > Avaa silti. Vaihtoehto päätteessä:
   xattr -dr com.apple.quarantine /Applications/YouHost.app

4. Salli mikrofoni ja äänitulo, kun macOS kysyy.

5. Käynnistysikkunassa valitse äänikortti.


YouHost — INSTALL
=================

1. Unzip the file (double-click).

2. Move YouHost.app to Applications.

3. On the first launch macOS may block the app. Right-click YouHost.app and choose Open. Or open System Settings > Privacy & Security > Open Anyway. Optional Terminal command:
   xattr -dr com.apple.quarantine /Applications/YouHost.app

4. Allow the microphone and audio input when macOS asks.

5. In the startup window, choose the audio card.
